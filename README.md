# Farveværksted

Personligt farveværktøj i én HTML-fil: konverter (HEX, RGB, HSL, CMYK, Pantone, LAB, OKLCH), harmonier, paletbygger, visualisering, gradient, mixer, kontrasttjek og farver fra billede.

Ingen build. Åbn `index.html` eller deploy mappen som statisk side.

Pantone-værdierne er vejledende og kommer fra npm-pakken `pantone-colors` (MIT).
